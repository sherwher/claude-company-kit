# Skill Packs

이 디렉터리는 공통 skill을 워커별 목적에 맞게 묶은 pack manifest를 둡니다.

## 기본 원칙

- pack은 skill 자체가 아니라 추천 묶음입니다.
- 워커 스폰 시 어떤 skill을 우선 참고할지 정하는 기준으로 씁니다.
- 프로젝트에서는 `.company-project/skills/enabled-packs.txt`와 `team-pack-overrides.txt`로 pack 사용 범위를 조정합니다.
