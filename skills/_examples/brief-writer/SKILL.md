# Skill: brief-writer

## 목적

- 짧은 topic을 실행 가능한 brief로 정리한다.

## 언제 사용하나

- 사용자의 요청이 모호할 때
- 워커 스폰 전에 입력을 정리해야 할 때

## 입력

- topic
- desired output
- constraints

## 출력

- 1페이지 이내 brief
- primary worker 추천
- open questions

## 절차

1. topic을 한 줄로 요약한다.
2. 필요한 결과물을 3개 이하로 압축한다.
3. 제약사항을 분리한다.
4. 적절한 primary worker를 제안한다.
5. 열어둘 질문이 있으면 3개 이하로 남긴다.

## 주의사항

- 장문 문서로 확장하지 않는다.
- 워커 스폰 전 입력 정리에만 집중한다.
