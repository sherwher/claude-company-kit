# Playtest Report

## 목적

- 플레이테스트 세션 데이터를 정량(수치)과 정성(관찰) 데이터로 분리해 객관성을 확보한다.
- 버그를 심각도(critical/major/minor)로 분류해 수정 우선순위를 즉시 결정할 수 있게 한다.
- UX 피드백을 구체적인 개선 제안으로 변환해 다음 이터레이션에 반영한다.

## 언제 사용하나

- game-qa가 내부 플레이테스트 세션을 마무리할 때
- 외부 플레이테스터 피드백을 취합하고 정리할 때
- 마일스톤 리뷰 전 품질 기준을 확인할 때
- balance-review와 함께 밸런스 데이터를 제공할 때

## 기본 절차

1. 테스트 범위(빌드 버전, 테스트 범위, 참여자 수)를 기록한다.
2. 세션 데이터를 수집한다 (클리어 시간, 사망 횟수, 재화 획득량 등).
3. 버그를 심각도별로 분류한다:
   - **Critical**: 게임 진행 불가, 데이터 손실
   - **Major**: 핵심 기능 오작동, 회피 불가능
   - **Minor**: 시각적 결함, 낮은 재현율
4. 밸런스 데이터를 분석한다 (클리어율, 구간별 사망 분포).
5. UX 관찰 사항을 구체적 장면으로 기록한다.
6. 개선 제안을 우선순위와 함께 정리한다.
7. `project-work/08-reviews/playtest-<날짜>.md`에 저장한다.

## Quick Template

```markdown
# 플레이테스트 리포트: <빌드 버전>

- 날짜: <YYYY-MM-DD>
- 작성자: <game-qa>
- 빌드: <v0.x.x>
- 테스트 범위: <예: 1~3챕터, 튜토리얼>
- 참여자: <내부 X명 / 외부 Y명>

---

## 1. 테스트 환경
- 플랫폼: <PC / 모바일>
- 해상도/프레임: <1920x1080 / 60fps 목표>
- 평균 플레이 시간: <분>

## 2. 정량 데이터
| 지표 | 수치 | 기준 | 판정 |
|------|------|------|------|
| 튜토리얼 완료율 | <80%> | >85% | ⚠️ |
| 1챕터 클리어율 | <65%> | >60% | ✅ |
| 평균 사망 횟수/런 | <3.2회> | <4회 | ✅ |
| 세션당 플레이 시간 | <42분> | 30-60분 | ✅ |

## 3. 버그 목록
### Critical
- [ ] <버그 설명> — 재현율: <100%> — 담당: <engineer-name>

### Major
- [ ] <버그 설명> — 재현율: <60%> — 담당: <engineer-name>

### Minor
- [ ] <버그 설명> — 재현율: <20%>

## 4. 밸런스 데이터
| 구간 | 사망 비율 | 판정 | 메모 |
|------|-----------|------|------|
| 튜토리얼 | <5%> | ✅ | |
| 1-1 보스 | <45%> | ⚠️ | 너무 어려움 |

## 5. UX 관찰
- <테스터 A: 인벤토리 버튼을 3회 연속 잘못 클릭 — 아이콘 가독성 문제>
- <테스터 B: 맵 이동 후 목표 위치를 파악하는 데 30초 소요 — 방향 표시 부재>

## 6. 개선 제안
| 우선순위 | 항목 | 제안 | 담당 |
|----------|------|------|------|
| P0 | <Critical 버그 수정> | — | <engineer> |

| P2 | <인벤토리 아이콘 크기 +20%> | 가독성 개선 | <game-artist> |
```

## Anti-Patterns

❌ "재밌었다/재미없었다" 정성 피드백만 기록 — 수정 액션으로 연결 불가
❌ 버그 심각도 분류 없이 목록만 나열 — 우선순위 결정 불가
❌ 밸런스 수치 없이 "너무 어렵다" 의견만 — 객관적 조정 기준 없음

## Golden Standard

```markdown
# 플레이테스트 리포트: v0.4.1

- 날짜: 2026-04-10
- 작성자: game-qa
- 빌드: v0.4.1
- 테스트 범위: 튜토리얼 + 챕터 1 전체
- 참여자: 내부 4명, 외부 6명

## 2. 정량 데이터
| 지표 | 수치 | 기준 | 판정 |
|------|------|------|------|
| 튜토리얼 완료율 | 90% | >85% | ✅ |
| 챕터 1 클리어율 | 55% | >60% | ⚠️ |
| 평균 사망/런 | 4.8회 | <4회 | ❌ |

## 3. 버그 목록
### Critical
- [ ] 보스 처치 후 보상 창 미출력 — 재현율 100% — 담당: backend-engineer

### Major
- [ ] 2-3 구간 폴아웃 후 리스폰 위치 오류 — 재현율 70%

## 6. 개선 제안
| 우선순위 | 항목 | 제안 |
|----------|------|------|
| P0 | 보상 창 버그 | 즉시 수정 후 재빌드 |
| P1 | 챕터 1 보스 HP | 300 → 250 감소 |
| P2 | 이동 튜토리얼 | 화살표 UI 추가 |
```
