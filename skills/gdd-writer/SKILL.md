# GDD Writer

## 목적

- 게임 시스템 전체를 하나의 문서로 구조화해 팀 공유 기준점을 만든다.
- 핵심 루프, 이코노미, 밸런스 초안을 한 문서에서 관리해 일관성을 유지한다.
- 엔지니어/아티스트/QA가 각자 필요한 섹션을 독립적으로 참조할 수 있게 한다.

## 언제 사용하나

- 게임 컨셉 확정 후 상세 시스템 설계가 필요할 때
- 개발 착수 전 팀 전체가 공유할 기준 문서가 필요할 때
- game-designer가 시스템 간 의존성을 정리할 때
- 신규 팀원 온보딩 자료가 필요할 때

## 기본 절차

1. `project-work/11-game-design/game-concept.md`를 읽어 컨셉을 확인한다.
2. 핵심 루프(Core Loop)를 단계별 다이어그램으로 설계한다.
3. 게임 내 시스템 목록을 열거하고 각 시스템의 책임을 한 줄로 정의한다.
4. 이코노미 모델(자원 생성/소비/변환)을 표로 정리한다.
5. 밸런스 초안 — 핵심 수치(데미지, HP, 비용 등)를 스프레드시트 행 형식으로 작성한다.
6. 진행 곡선(난이도/콘텐츠 오픈 타임라인)을 시각화한다.
7. UI/UX 가이드라인 요약을 첨부한다.
8. `project-work/11-game-design/gdd-template.md`에 저장한다.

## Quick Template

```markdown
# GDD: <게임 제목>

- 버전: <v0.1>
- 날짜: <YYYY-MM-DD>
- 작성자: <game-designer>
- 컨셉 참조: `project-work/11-game-design/game-concept.md`

---

## 1. 개요
<게임 핵심 재미 한 문장>

## 2. 핵심 루프 (Core Loop)
```
[시작] → 탐색 → 전투/도전 → 보상 획득 → 성장/업그레이드 → [반복]
```

## 3. 시스템 설계
| 시스템명 | 책임 | 의존 시스템 |
|----------|------|-------------|
| <전투> | <데미지 계산, 상태이상 처리> | <캐릭터, 아이템> |
| <인벤토리> | <아이템 저장/사용> | <이코노미> |

## 4. 이코노미 모델
| 자원명 | 생성 방법 | 소비 방법 | 상한 |
|--------|-----------|-----------|------|
| <골드> | <몬스터 처치, 퀘스트> | <상점 구매> | <9999> |

## 5. 밸런스 초안
| 구분 | 수치 | 비고 |
|------|------|------|
| 플레이어 기본 HP | <100> | <레벨당 +10> |
| 기본 공격력 | <10> | <무기 보정 별도> |

## 6. 진행 곡선
- 1-3시간: <튜토리얼 완료, 핵심 루프 체감>
- 5-10시간: <시스템 심화, 첫 보스 클리어>
- 20시간+: <엔드게임 콘텐츠, 반복 플레이>

## 7. UI/UX 가이드라인
- HUD 핵심 요소: <HP바, 자원 표시, 미니맵>
- 인터랙션 원칙: <3-click rule — 주요 액션은 3번 이내 조작으로 완료>
```

## Anti-Patterns

❌ 시스템 목록만 나열하고 의존성 없음 — 개발 시 충돌 발생
❌ 수치 없는 밸런스 섹션 — "적당히"는 밸런스 기준이 아님
❌ 한 문서에 모든 결정을 영구히 — 변경 이력 없이 덮어쓰면 롤백 불가

## Golden Standard

```markdown
# GDD: Echoes of the Void v0.3

- 버전: v0.3
- 날짜: 2026-04-10
- 작성자: game-designer
- 컨셉 참조: `project-work/11-game-design/game-concept.md`

## 2. 핵심 루프
```
[런 시작] → 카드 드래프트 → 전투 → 유물/카드 보상 → [다음 방] → 보스 → [런 종료/계속]
```

## 3. 시스템 설계
| 시스템명 | 책임 | 의존 시스템 |
|----------|------|-------------|
| 덱 빌딩 | 카드 드래프트, 덱 관리 | 전투, 상점 |
| 전투 | 턴 기반 카드 사용, 데미지 계산 | 덱 빌딩, 유물 |
| 유물 | 패시브 효과 제공 | 전투, 이코노미 |
| 상점 | 카드/유물 구매 | 이코노미 |

## 4. 이코노미
| 자원 | 생성 | 소비 | 상한 |
|------|------|------|------|
| 골드 | 전투 승리(10-30), 보물방(50) | 상점 구매 | 999 |
| 카드 | 보상 드래프트 | 덱에 추가 | 무제한 |

## 5. 밸런스 초안
| 구분 | 수치 |
|------|------|
| 시작 HP | 80 |
| 시작 마나 | 3/턴 |
| 기본 공격 카드 데미지 | 6 |
| 기본 방어 카드 블록 | 5 |
```
