# Level Brief

## 목적

- 레벨의 목적(학습/전투/탐험)을 명확히 해 제작 방향을 고정한다.
- 플레이어 동선과 인카운터 배치를 사전에 설계해 화이트박스 제작 비용을 줄인다.
- 페이싱 차트로 긴장감과 이완을 의도적으로 배치해 플레이어 경험을 설계한다.

## 언제 사용하나

- level-designer가 새 레벨 제작을 시작할 때
- 화이트박스(blockout) 제작 전 레이아웃 합의가 필요할 때
- game-designer와 level-designer가 인카운터 난이도를 조율할 때
- 레벨 리뷰/플레이테스트 전 기준 문서가 필요할 때

## 기본 절차

1. 레벨의 목적을 한 문장으로 정의한다 (가르침/전투/스토리 전달 등).
2. 플레이어 진입/진출 동선을 2D 스케치 또는 텍스트 맵으로 그린다.
3. 인카운터 배치 테이블을 작성한다 (위치, 적 구성, 난이도).
4. 페이싱 차트를 작성한다 — 긴장(High)/이완(Low)/중간(Mid) 구간.
5. 환경 퍼즐 또는 탐험 요소를 별도로 기술한다.
6. 예상 클리어 시간과 난이도 곡선을 명시한다.
7. `project-work/11-game-design/level-<번호>-<이름>.md`에 저장한다.

## Quick Template

```markdown
# 레벨 브리프: <레벨 번호> — <레벨명>

- 날짜: <YYYY-MM-DD>
- 작성자: <level-designer>
- 상태: 초안 / 검토 중 / 확정

## 레벨 목적
> <이 레벨에서 플레이어가 배우거나 경험해야 하는 것>

## 기본 정보
- 예상 클리어 시간: <분>
- 추천 레벨/스펙: <예: 캐릭터 레벨 5-8>
- 주요 메카닉: <이 레벨에서 처음 등장하거나 심화되는 메카닉>

## 플레이어 동선
```
[입구] → A구역(탐험) → B구역(전투) → C구역(퍼즐) → [출구/보스]
         ↘ 선택 경로(숨겨진 방) ↗
```

## 인카운터 테이블
| 구역 | 적 구성 | 난이도 | 특이사항 |
|------|---------|--------|----------|
| B-1 | <슬라임 x3> | Low | <첫 전투, 튜토리얼 힌트 표시> |
| B-2 | <슬라임 x2 + 궁수 x1> | Mid | <원거리 적 첫 등장> |
| 보스 | <<보스명>> | High | <페이즈 2 진입 시 BGM 전환> |

## 페이싱 차트
| 구간 | 긴장도 | 내용 |
|------|--------|------|
| 0-20% | Low | 탐험, 환경 파악 |
| 20-50% | Mid→High | 전투 증가 |
| 50-70% | Low | 퍼즐/보물방, 이완 |
| 70-100% | High | 보스전 |

## 환경 요소
- 퍼즐: <설명>
- 숨겨진 요소: <설명>
- 환경 위험: <함정, 낙사 구간 등>

## 난이도 메모
<밸런스 팀에 전달할 특이사항>
```

## Anti-Patterns

❌ 동선 없이 "자유 탐험" — 플레이어가 목표를 잃고 이탈
❌ 인카운터 표 없이 "적 배치는 구현 중 결정" — 밸런스 기준 없음
❌ 페이싱 없이 전투만 연속 — 플레이어 피로도 급증

## Golden Standard

```markdown
# 레벨 브리프: 03 — The Shattered Vault

- 날짜: 2026-04-10
- 작성자: level-designer
- 상태: 확정

## 레벨 목적
> 플레이어가 원거리 적과 근접 적을 동시에 처리하는 포지셔닝 전략을 익힌다.

## 기본 정보
- 예상 클리어 시간: 12-18분
- 추천 레벨: 캐릭터 레벨 7-10
- 주요 메카닉: 엄폐물 활용, 원거리 어그로 관리

## 플레이어 동선
```
[입구] → 전실(Low) → 메인홀(Mid) → 금고문 퍼즐(Low) → 보스룸(High)
                    ↘ 비밀통로(선택, 아이템 보상) ↗
```

## 인카운터 테이블
| 구역 | 적 구성 | 난이도 | 특이사항 |
|------|---------|--------|----------|
| 전실 | 경비병 x2 | Low | 엄폐물 튜토리얼 팝업 |
| 메인홀 | 경비병 x2 + 저격수 x1 | Mid | 저격수 첫 등장 |
| 보스룸 | Vault Keeper | High | 페이즈 2 시 소환 추가 |

## 페이싱 차트
| 구간 | 긴장도 | 내용 |
|------|--------|------|
| 0-25% | Low | 전실 전투 + 환경 파악 |
| 25-60% | High | 메인홀 전투 |
| 60-80% | Low | 금고문 퍼즐, 아이템 수집 |
| 80-100% | High | 보스전 |
```
