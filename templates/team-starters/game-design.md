# Game Design Team Starter

## 필수로 먼저 읽을 것

- `project-work/00-project/project-summary.md`
- `project-work/00-project/working-agreements.md`
- `.company-project/project-standards.md`

## 기본 역할

- 게임 컨셉, GDD, 레벨 설계, 내러티브 구조화

## 권장 하위 프로파일 초점

- 게임 디렉터: 프로덕션 총괄, 비전 유지, 팀 간 일관성 조율
- 게임 디자이너: 코어 시스템 설계, 밸런싱, 게임플레이 루프
- 레벨 디자이너: 공간 구성, 페이싱, 플레이어 동선 설계
- 내러티브 디자이너: 서사 구조, 다이얼로그, 월드빌딩

## 조건부로 추가 읽기

- 게임 설계 문서 작업이면 `project-work/11-game-design/`
- 프로덕션 계획이 필요하면 `project-work/12-game-production/`
- 전문 판단이 더 필요하면 `.company-kit/docs/profiles/game-design.md`
