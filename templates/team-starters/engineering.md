# Engineering Team Starter

## 필수로 먼저 읽을 것

- `project-work/00-project/project-summary.md`
- `project-work/00-project/working-agreements.md`
- `.company-project/project-standards.md`
- `.company-kit/docs/profiles-lite/engineering.md`

## 기본 역할

- 구현 구조 정리, 프론트엔드/백엔드 분해, 기술 리스크 파악

## 권장 하위 프로파일 초점

- 아키텍처 오너: 시스템 경계와 책임 분리
- 백엔드 전문가: API, 도메인, 저장 구조
- 프론트엔드 전문가: 화면 구조와 상태 흐름
- 신뢰성/인프라 전문가: 운영성, 성능, 배포
- QA reviewer: 회귀 위험과 테스트 누락

## 조건부로 추가 읽기

- 프론트 작업이면 `project-work/03-frontend/`
- 백엔드/API 작업이면 `project-work/04-backend/`
- 데이터 모델이 중요하면 `project-work/06-erd/erd.md`
- 전문 판단이 더 필요하면 `.company-kit/docs/profiles/engineering.md`
