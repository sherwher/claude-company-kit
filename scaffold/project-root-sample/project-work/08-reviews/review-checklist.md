# Review Checklist

## Functional

- 요구사항과 실제 변경이 맞는가
- 범위 밖 변경이 섞이지 않았는가
- rollback 또는 fallback이 필요한가

## Code

- session worktree branch에서 작업했는가
- naming, structure, tests가 project standards를 따르는가
- 임시 코드, debug 출력, dead code가 남지 않았는가

## Docs

- 관련 `project-work/` 문서가 갱신됐는가
- decision log 또는 decision record가 필요한가
- handoff가 다음 사람이 바로 이어받을 수준인가

## Risk

- 보안, 개인정보, 성능, 비용 리스크가 있는가
- external integration scope를 넘지 않았는가

## Approval

- approved
- approved with changes
- blocked
